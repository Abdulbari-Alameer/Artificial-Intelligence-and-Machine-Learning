# Artificial Intelligence and Machine Learning

Machine learning projects from my Master's in Computer Science & Engineering at Tezpur University and from related courses. Each project sits in its own folder with a README that explains the method, the results and how to run it.

## Projects

| Project | Summary | Tools |
|---|---|---|
| [Telecom Churn Retention Proposal](Telecom-Churn-Retention-Proposal) | Churn prediction for a mobile operator with 100,000 customers, from data checks and analysis to a LightGBM model (test ROC-AUC 0.699) and a costed retention proposal tested by a pilot. Final assignment, GCI World 2026 (Matsuo-Iwasawa Lab, The University of Tokyo). | Python, pandas, scikit-learn, LightGBM |
| [Anomaly Scoring with KNN and Density](Anomaly-Scoring-KNN-Density) | An anomaly score in [0, 1] that combines normalized k-nearest-neighbour distance with deviation from a density threshold, plus automatic threshold estimation and plots. | Python, NumPy, scikit-learn, Matplotlib |
